# 统一训练标准

2026-11-05 起，正式启动配置统一选择 `unified_v1`。规则定义集中在
`weiqi/training_standard.py`，普通 PyTorch 训练、KataGo 课程训练和 Mac 混训共同使用。

| 项目 | 统一口径 |
| --- | --- |
| 冠军晋级 | 完整换色配对，候选总得分率至少 55%，每个受评棋盘至少 50% |
| 得分率 | 胜记 1 分、和记 0.5 分、负记 0 分 |
| 正式确认赛 | 每个受评棋盘 40 局，32 visits；混训先做每盘 12 局初筛 |
| 评测间隔 | 每累计 51,200 个实际完成优化器更新的训练样本；更换批量不重置进度 |
| 置信区间 | 继续记录供参考，不作为 `unified_v1` 的额外否决条件 |
| 健康检查 | 至少 32 局；黑方得分率 10%–90%，开局双停不超过 5%，短局不超过 25%，无效棋局不超过 5%，停着比例不超过 20% |
| 短局定义 | 着数少于 `max(4, ceil(棋盘面积 × 10%))` |
| 极端分差 | 绝对分差至少棋盘面积的 75%；仅作观察 |

正式评测有无效棋谱、缺少局数或缺少换色配对时不能晋级。
Mac 在全部训练棋盘上另做隔离健康探测；普通版使用已记录的近期自对弈健康窗口。
普通版与历史对手的对局仍检查长度、停着和有效性；黑白平衡只采用候选与自身对弈的记录，
至少 32 局可比自对弈后才允许晋级。已有健康指标没有记录的短局或停着计数不补造为零，
新记录会保存这些计数。Mac 冠军异常及普通版已确认的自对弈异常会停止继续摄入数据。

Mac 配置在 `promotion.standard` 选择标准；普通版和单棋盘 KataGo 配置在
`overrides.evaluation.standard` 选择；课程配置在根字段 `training_standard` 选择。
标准选中后，旧的胜率、评测局数、评测搜索量和轮次间隔字段不能覆盖公共规则。
训练期间的搜索策略、网络结构、棋盘课程与模型格式仍由相应后端配置负责；
CPU、MPS、CUDA 配置只决定运行资源和数值精度，不改变晋级门槛。

Mac 仍以 8、9、13、19 路进行晋级对战，7 路继续参与训练及健康检查。
RTX 课程仍依次训练 9、13、19 路。课程切换还需达到阶段最低样本数并连续通过两次
固定历史基准评测；这与替换当前冠军是两项独立判断。

新评测会记录所用标准、局数、搜索量和开局协议。Mac 中已开始的旧评测沿用冻结的旧规则。
旧课程评测没有完整的门槛快照；切换标准时会明确记录延期并保留原棋谱，新标准另开评测，
避免推测旧门槛或混用两套成绩。旧历史结果不会按新门槛重新判定。
Mac 剩余轮次会一次换算为剩余样本，保留当前进度。
没有选择标准的旧配置继续使用旧逻辑，以便复现实验。

普通版旧检查点可通过策略覆盖文件选择标准后续训，保留模型、优化器和回放：

```json
{"evaluation": {"standard": "unified_v1"}}
```

将该 JSON 作为 `train.py train --resume ... --policy-overrides ...` 的参数。
网页会显示统一门槛、下次评测的实际样本水位和剩余样本。
